# Project history and attribution

Parallel began as a hackathon prototype. This evidence review was performed on 9 November 2026. Historical awards describe those prototypes, not live integration or production certification of today's implementation.

## Three events, four award results

- **Scoop AI Hackathon Silicon Valley Bowl:** the [Neo News Today published results](https://neonewstoday.com/ai/neo-and-spoonos-announce-winners-of-scoop-ai-hackathon-silicon-valley-bowl/) explicitly place Parallel among three second-place teams. This is a published secondary report; it links the [SpoonOS announcement](https://x.com/SpoonOS_ai/status/1993241783736869055), which could not be fetched directly in this review. The supplied first-place recollection conflicts with the explicit results; use second place unless stronger organizer evidence corrects it. The owner-supplied [Yug announcement](https://www.linkedin.com/posts/yugmore13_48-hours-zero-sleep-one-turning-point-activity-7399135503683571712-kQk6) and [Sean announcement](https://www.linkedin.com/posts/sean-aminov_hackathon-spoonos-parallelos-activity-7399594794231996416-HxUu) both confirm a win without specifying first place. The [official event website](https://scoop.spoonai.io/) establishes SpoonOS/event context but does not list Parallel as first. The README therefore uses “Winning team,” which is supported by all these records.
- **Meet the Vibes with TRAE Friends @ Silicon Valley:** the [Ainovo organizer page](https://www.linkedin.com/company/ainovoco/) names Parallel the first-place winner of its pitch/demo event. An organizer announcement reshared on [Nayab Hossain's profile](https://www.linkedin.com/in/nayabhossain) uses the full event name and grand-winner description. The [Parallel team announcement](https://www.linkedin.com/posts/paralleldev_ai-startup-parallel-activity-7405709912682463232-4XuK) independently supplies first-place/grand-prize wording but is team-authored. This is a pitch/demo competition; do not relabel it a coding hackathon.
- **Continual Learning Hackathon:** the [Devpost project record](https://devpost.com/software/parallel) lists **Composio Best of Use** and **Best Voice agent using Plivo** as winner categories. These are two track wins within one event. [Yug More's account](https://www.linkedin.com/posts/yugmore13_68-teams-200-hackers-two-track-wins-activity-7426742140065693697--u9G) and [Sean Aminov's account](https://www.linkedin.com/posts/sean-aminov_hackathon-startups-voiceai-activity-7426737824244084736-Dchz) call it the Google DeepMind Continual Learning Hackathon and thank Intercom among the participants/hosts. Use Devpost's event title rather than treating “Intercom San Francisco” as another competition.

The earlier repository history said Global Scoop AI Hackathon and Continual Learning Hackathon, with an aggregate award claim explicitly marked owner-supplied and unverified. That record remains in Git history. The new request said Scoop first place, TRAE first place and two Intercom tracks. The linked records now support three distinct events and four award results, with the Scoop ranking correction. An additional first-place Scoop award is not substantiated by the records inspected. The [official TRAE listing](https://luma.com/b1ii8quj) confirms the pitch/demo format and Plug and Play Tech Center, Sunnyvale venue. No award images/certificates were found in tracked paths; existing screenshots and all historical files were preserved.
