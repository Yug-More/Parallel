## 75-word description

Six deterministic local agent contracts compute bounded reports and task proposals through a persistent worker. Exact owner approvals and atomic receipts govern native changes. A forty-query developer-created holdout produced 90% recall@5 and 0.818 MRR. Historical prototypes earned recognition at three competitions. ## 150-word technical description

Parallel uses React and Vite with a FastAPI modular monolith, SQLAlchemy persistence and Alembic migrations. A worker shares the migrated database and processes document ingestion, local agent runs and approved native effects. Six code-defined contracts cover status, dependency analysis, handoffs, explicit task planning, context research and delivery coordination. Coordinators preserve child outcomes and reject inconsistent context rather than silently combining stale reports.

Authorization uses immutable user IDs, live database sessions and current workspace membership. Workspace locks serialize mutations; tasks require current versions and valid prerequisites. Decisions preserve correction reasons, revisions and immutable source references. Revocable knowledge invalidates stale derived text. Owner approvals bind exact payloads, context and expiration before worker revalidation commits one atomic receipt.

Retrieval is lexical: forty developer-created holdout queries yielded 90% recall@5 and 0.818 MRR. PostgreSQL, browser and Docker checks test persisted behavior. External writes remain disabled; optional trained models and private integrations require separate live validation.

## 250-word research-oriented description

Parallel investigates an engineering question: how can a collaborative workspace preserve project context while keeping automated actions bounded, attributable and reversible where possible? Conversations alone do not distinguish accepted decisions from suggestions, and retrieved text cannot safely confer authority. The system therefore separates human-authored records, immutable source references, derived interpretations and execution receipts.

A React interface exposes a FastAPI modular monolith with persistence. Versioned tasks and revision-preserving decisions supply structured project state. Permission-aware lexical retrieval connects questions and local computations to evidence within the authenticated workspace. Revocation advances knowledge state so stale derived reports cannot remain available merely because they were generated.

Six deterministic agent contracts analyze status, dependencies, explicit plans and source excerpts. Coordinators persist delegation and compose child outcomes only when context fingerprints agree. Database leases, cancellation, bounded retries and current membership checks address interruption and concurrent execution. Proposed native changes require owner approval bound to the exact action, payload and context; a separate worker rechecks those conditions before committing effects and a receipt atomically.

Evaluation separates behavior from intelligence claims. A frozen developer-created forty-query holdout produced 90% recall@5 and 0.818 MRR for default lexical retrieval. These labels are not independently adjudicated, and paraphrase, ambiguity and multilingual failures remain. Browser, backend, PostgreSQL and Docker checks exercise persistence and control boundaries without paid providers. Historical competition awards establish prototype recognition, not model quality or production adoption. Future work requires independent relevance judgments, usability studies and live provider validation before broader claims about autonomous collaboration or deployment readiness become defensible.

## 200-word technical description

Parallel is a workspace for human collaboration and bounded local agents. React and Vite provide the interface; FastAPI, SQLAlchemy and Alembic implement a modular monolith backed by SQLite or PostgreSQL. A worker shares the migrated database rather than relying on ephemeral process memory.

Six deterministic contracts compute project status, dependency chains, handoffs, explicit task plans, context research and coordinated delivery proposals. Persistent child runs expose delegation and outcomes. Lease tokens, bounded attempts, cancellation and context fingerprints prevent late or inconsistent results from becoming accepted state. Exact owner approval governs native task creation and report publication. The worker rechecks authority, context and payload before recording effects with an atomic receipt.

Live database sessions and immutable membership authorize workspace resources. Optimistic task versions, prerequisite validation and revision-preserving decisions protect collaborative edits. Source revocation hides stale derived text. Document ingestion uses bounded text handling and an isolated PDF subprocess; GitHub imports remain enabled and read-only.

On forty developer-created holdout queries, default lexical retrieval achieved 90% recall@5 and 0.818 MRR. Automated verification covers backend, browser, PostgreSQL and real Docker workflows. These results demonstrate tested local behavior, not trained-model quality, unrestricted autonomous execution, verified production adoption or independently established research performance under representative deployment conditions.

## Engineering challenges and decisions

Keeping cached evidence private after revocation required knowledge epochs and read-time evidence checks. Coordinators needed persistent child plans and matching fingerprints to avoid composing inconsistent snapshots. Approval needed to bind a concrete payload and survive authority changes without granting permanent execution permission. Lease expiry and cancellation needed explicit failure states instead of inferred success. The modular monolith and database queue keep these boundaries inspectable without unnecessary distributed infrastructure. The finalization cycle fixed a missing Docker worker, patched seven PDF dependency advisories and removed disabled legacy routes from the supported API specification.

## Faculty interview questions and evidence-based answers

**Are these LLM agents?** The six execution contracts are deterministic local computation. Optional cited model answers/reasoning are separately opted into and never control native effects. No live model-quality evidence is claimed.

**What does multi-agent coordination add?** Persisted status/dependency or planner/research child runs expose separate responsibilities. Coordinators verify common context before aggregation. This is bounded delegation, not arbitrary autonomous software execution.

**How do you avoid duplicate actions?** Idempotency keys deduplicate requests; leases constrain worker claims; exact approval and atomic effect/receipt transactions protect the allowed native actions. Repository writes and external messages remain unavailable.

**Can retrieval leak another user's data?** Resource resolution checks current membership and immutable workspace/source IDs. Regression suites test cross-workspace denial and revocation; those tests do not establish that every possible attack is ruled out.

**How strong is 90% recall?** It is recall@5 on forty synthetic developer-created holdout cases. The judgments are not independent; strict precision@5 is only 0.170. Vocabulary and multilingual misses remain. It is a reproducible fixture result, not general semantic understanding.

**What would you investigate next?** Independent relevance labeling, representative workloads, usability/accessibility with actual participants, and live provider authorization/quality. Production operation additionally needs reviewed credential lifecycle, supervision, offsite backup/restoration and deployment controls.

**What did the awards validate?** Historical prototypes received event recognition. The two continual-learning wins are tracks at one event; Scoop was second place. They do not certify today's security, adoption or disabled integrations.
