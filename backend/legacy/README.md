# Historical reference only

These files preserve prior implementation ideas and are renamed .disabled so Python tooling does not execute them. They contain unsafe assumptions (global context, editable-name identities, unauthenticated callbacks, best-effort external success reporting) and incompatible imports. They are not imported by the runtime, not installed as dependencies, and not live integration support. Use Git history for original authorship. Reimplementation requires the security and approval boundaries described in ../../docs/SECURITY.md.
